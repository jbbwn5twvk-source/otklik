# Отклик — лента заказов и Telegram-бот

Каждые 30 минут GitHub Actions бесплатно собирает заказы с **Kwork**, **hh.ru** и 14 **Telegram-каналов**, оставляет подходящие (презентации, Excel, тексты, Python, сайты) и:

- обновляет ленту на сайте `https://<логин>.github.io/otklik/`;
- присылает **новые** заказы в Telegram-бот: ссылка, цена, оценка времени «Claude + вы»;
- присылает **сообщения заказчиков с Авито и Kwork** (по письмам-уведомлениям в Gmail).

Токены Claude не тратятся.

## Запуск

### 1. Telegram-бот
1. **@BotFather** → `/newbot` → имя и логин на `bot`. Сохраните токен `123456:ABC…`, никому его не показывайте.
2. Откройте своего бота и нажмите **Start**.
3. Напишите **@userinfobot** — он пришлёт ваш `Id`.

### 2. Секреты
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Имя | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен от BotFather |
| `TELEGRAM_CHAT_ID` | ваш Id от @userinfobot |
| `GMAIL_USER` | адрес Gmail (для сообщений Авито и Kwork) |
| `GMAIL_APP_PASSWORD` | пароль приложения Google, 16 букв |

### 3. Сайт и первый запуск
1. **Settings → Pages** → *Deploy from a branch* → `main`, папка `/docs` → Save.
2. **Actions** → *Обновить ленту* → **Run workflow**.
3. Через 1–2 минуты бот напишет «✅ Лента подключена».

## Сообщения заказчиков (Авито и Kwork)
1. **Авито:** Профиль → Настройки → Уведомления → включите письма о новых сообщениях.
2. **Kwork:** Настройки → Уведомления → включите письма о новых сообщениях и заказах.
3. **Google:** включите двухэтапную аутентификацию → myaccount.google.com/apppasswords → создайте пароль приложения → секрет `GMAIL_APP_PASSWORD`.

Скрипт читает только письма от avito.ru и kwork.ru и не помечает их прочитанными. Задержка — до 30 минут; для мгновенных уведомлений держите включёнными push в приложениях Авито и Kwork.

## Настройка
Всё в `scraper/config.py`: категории и стоп-слова, список каналов `TG_CHANNELS`, `KWORK_MAX_PRICE`, запросы `HH_QUERIES`, оценки времени `TIME`, отправители писем `MAIL_SENDERS`.

Если какая-то площадка перестанет читаться, бот один раз напишет «⚠️ … не читается» — перешлите это Claude.
